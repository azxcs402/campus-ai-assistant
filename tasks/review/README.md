# tasks/review · 复核中

存放**实现完成、等待交叉检查或人工复核**的任务文件。

## 使用规则

1. 任务从 `tasks/doing/` 移入本目录时，「当前状态」改为 `review`；
2. 复核内容：对照任务文件的「完成标准」逐项核验；检查「不允许修改的范围」未被突破；按 [AGENTS.md](../../AGENTS.md) 第 6 节跑一致性清单；
3. 复核发现问题的任务回到 `tasks/doing/`（状态改回 `doing`）并注明原因；通过后移动到 `tasks/done/`（状态改为 `done`）；
4. 复核人建议由另一 Agent 或人工完成（交叉检查，避免自审自过）。

> 当前无复核中任务。
