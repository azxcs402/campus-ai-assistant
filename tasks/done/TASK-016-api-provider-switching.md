# TASK-016 多 API 配置与切换

- 状态：done
- 负责 Agent：Codex
- 范围：AI 学习助手的 API 配置入口、配置管理和按消息切换

## 完成标准

- 用户可在网页中添加多个 API 配置。
- 每个配置可自定义名称、Base URL、模型名称和 API Key。
- 用户可在聊天区域切换当前 API。
- 配置仅保存在当前浏览器，不提交密钥到仓库。
- 后端支持接收当前消息的临时 provider 配置，并继续兼容环境变量配置。
- 配置失败时显示可读错误，不影响任务和资料功能。

## 安全边界

- API Key 使用密码输入框并仅存储在浏览器 localStorage。
- 不写入 Git、项目数据库、日志或页面可见文本。
- 页面明确提示：浏览器本地存储不适合共享电脑或生产环境。

## 实际结果

- AI 面板增加 API 选择器和“管理 API”入口。
- 支持新增、编辑、删除多个 API 配置，并自定义配置名称。
- 支持配置 Base URL、模型名称和 API Key。
- 当前选中的配置随聊天请求发送到后端，后端兼容原有环境变量模式。
- 增加 Base URL 校验测试，完整测试结果：`8 passed`。
