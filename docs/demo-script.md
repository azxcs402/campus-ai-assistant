## 1. 演示主线（一句话）

> **登录 → 添加学习任务 → 标记完成看到统计变化 → 问 AI「怎么安排」→ 把 AI 建议转成一条真实任务 → 回到任务闭环收尾**：证明它不是聊天机器人，而是「AI 建议可以落成任务管理闭环」的可运行系统。

主线设计动机：全部由**已实现功能**串联；计划中功能只在「局限与下一步」段落用一句话说明，不打断主线。

## 3. 演示前检查单（建议提前 30 分钟执行）

**环境与启动**
- [ ] 确认 Python 可用；后端虚拟环境存在：`backend/.venv\Scripts\python.exe`（缺失则 `python -m venv .venv` 后 `pip install -r backend/requirements.txt`）；
- [ ] （可选，接真实模型）在**启动后端的同一个终端**设置环境变量再启动：`set LLM_API_KEY=...`、`set LLM_BASE_URL=https://api.deepseek.com/v1`、`set LLM_MODEL=deepseek-chat`。当前代码用 `os.getenv` 读取，不自动加载 `.env` 文件（`.env.example` 仅供参考字段名）；
- [ ] 端口空闲：8000（后端）、5500（前端）；
- [ ] 双击/终端运行 `run-backend.cmd`，等日志出现 uvicorn 启动、访问 `http://127.0.0.1:8000/api/v1/health` 应返回 `{"status":"ok"}`；
- [ ] 运行 `run-frontend.cmd`，浏览器打开 **`http://127.0.0.1:5500`**（必须是 5500，CORS 白名单仅含 5500/8000）；
- [ ] 网络检查：若演示真实 LLM，确认可访问 `LLM_BASE_URL`；若不确定，**默认用演示模式**（不配 key 即可，零网络风险）。

**数据准备（演示账号与预置数据）**
- [ ] 准备演示账号：注册 `demo_student / 密码≥6 位`（本机唯一）；把账号密码抄在纸条上，防止现场忘记；
- [ ] 预置 1 门课程（如「操作系统原理」）与 2~3 条任务（含 1 条未完成高优先级、截止日期选**未来日期**），任务在演示当天不过期；或接受前端**自动创建默认课程**（无课程时 `app.js` 自动建「系统设计与实践」）后现场现建；
- [ ] 数据隔离建议：演示前将 `DATABASE_PATH` 指向独立文件（如 `backend\..\data\demo.db`），或用干净库启动一次并预置；避免把现场临时任务留在开发库（可选，非必须）；
- [ ] 清空/重置数据的办法（需要时）：停止后端 → 删除/改名 `data/app.db` → 重启后端自动重建空库 → 重新注册演示账号（后端 `startup` 自动建表）。

**备用方案话术（提前背熟）**
- LLM 不可用时的演示模式话术：「AI 走的是可替换接口：现在没有配置密钥，系统自动进入演示模式、不依赖外网；配置 OpenAI 兼容密钥后即可切换真实模型。任务管理等功能不受 AI 可用性影响。」
- RAG 未实现时的说明话术：「基于自己上传资料的回答（RAG）在架构与需求里已设计好（FR-12~15），属于特色版计划，本轮演示的是基础闭环。」（不要讲成已实现）

## 5. 突发情况应对表

| 突发情况 | 现象 | 应对 |
| --- | --- | --- |
| 后端未启动 / 接口 500 / 连接拒绝 | 页面报错「请求失败」、无数据 | 检查 `run-backend.cmd` 终端是否在运行、8000 端口被占用则关掉占用进程重启；无法快速修复时声明「这是本地服务未启动」并演示结束，不硬撑 |
| AI 返回演示模式固定回复 | 回复含「演示模式：我已收到你的问题……」 | 话术：「现在没有配置密钥，系统自动降级为演示模式，回答是模板化的；配置 OpenAI 兼容密钥即切换真实模型。」并顺势走「闭环」步骤，展示模板提示词本身也引导把问题整理成任务 |
| 真实 LLM 超时/不可用 | 返回「AI 服务暂时不可用。请稍后重试，或继续使用任务管理功能。」 | 话术：「AI 服务超时，系统降级不阻断——这正是我们的容错设计（非 AI 功能不受影响）。」继续演示任务与统计 |
| 忘记演示账号 / 登录 401 | 「账号或密码错误」 | 现场用「注册」按钮 30 秒内注册新账号（需填昵称）；或换备用账号（纸条） |
| 前端样式错乱 / JS 报错 | 页面布局乱、按钮无反应 | 确认访问的是 `http://127.0.0.1:5500`（CORS 白名单）；浏览器 F12 看 Console；硬刷新 Ctrl+F5；确认 `run-frontend.cmd` 未中断 |
| CORS 跨域报错 | 控制台 CORS error、接口被拦 | 前端必须用 5500（白名单 `127.0.0.1:5500 / localhost:5500`），不要用 file:// 或其它端口打开 |
| 数据库里有上次演示脏数据 | 任务过多、统计不直观 | 重置：停后端 → 删除 `data/app.db` → 重启 → 重新注册账号；或使用独立 `DATABASE_PATH` 演示库 |
| 任务截止时间显示为昨日/过期 | 任务排序靠后或观感差 | 预置数据时截止日期一律选未来日期；演示当天新增任务也选未来日期 |
| 提问后 AI 迟迟无响应 | 转圈 > 10s | 真实模式单次超时上限 25s；超过即降级返回。等待期间话术「AI 生成中，我们的演示模式更快」，之后按超时话术处理 |
| 页面徽标「演示模式可用」与实际不符（接了真实模型仍显示） | 静态文案 | 徽标是 `index.html` 静态文字；演示时以**回复内容**说明当前模式，不要以徽标为准 |
