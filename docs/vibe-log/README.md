# vibe-log · 项目工作日志

本目录记录两个 Agent（DeepSeek 规划 Agent / Codex 实现 Agent）每轮工作的**事实性日志**：做了什么、改了哪些文件、关键决策与理由、遗留问题与待验证项。

## 规则（见 [AGENTS.md](../../AGENTS.md) 第 3 节）

1. 每次 Agent 工作结束，必须在此追加一条日志，命名建议 `YYYY-MM-DD-主题.md`；
2. 日志按时间正序排列，新日志追加到「日志索引」；
3. 内容只写事实与决策，不写推测；对假设内容注明「待验证」；
4. 涉及需求/编号变更时必须说明同步更新了哪些文档。
