# 演示截图与图注清单

## 使用方式

1. 在仓库外创建 `D:\桌面\campus-ai-assistant-demo`。
2. 按下表中的文件名保存截图，截图前隐藏无关窗口和真实个人信息。
3. 在课程报告或答辩 PPT 中插入对应图片，并直接使用“图注”列作为图片下方说明文字。
4. 图注描述可核验事实，不把“计划功能”写成“已实现功能”。

## 截图规则

- 浏览器地址栏可保留 `http://127.0.0.1:5500`，证明系统来自本地运行环境。
- 不显示 API Key、token、真实账号、学号、姓名和私人文件名。
- 使用同一浏览器窗口尺寸和同一测试账号完成截图。
- 截图前执行 `Ctrl+F5`，避免旧版 JavaScript 或 CSS 缓存。
- 每张截图只表达一个验证目标，避免一张图堆叠多个未说明功能。
