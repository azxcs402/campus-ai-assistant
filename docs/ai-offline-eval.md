## 2. 已实现的自动化离线检查（代码事实）

**文件**：`backend/offline_eval.py`（纯 Python，无第三方依赖）

- 数据结构：`EvaluationCase(case_id, prompt, required_terms)`（`@dataclass(frozen=True)`）。
- 内置 6 条样例 `CASES`：

| 样例 | prompt（用户输入） | required_terms（必须出现的关键词） |
| --- | --- | --- |
| E-01 | 把课程报告拆成可执行步骤 | 步骤、报告 |
| E-02 | 给出三天复习计划 | 第1天、第2天、第3天 |
| E-03 | 任务已经逾期怎么办 | 优先、截止 |
| E-04 | 如何安排两门课程 | 课程、时间 |
| E-05 | API Key 错误时怎么办 | 检查、重试 |
| E-06 | 总结学习资料的下一步 | 资料、下一步 |

- 评分函数 `score_output(case, output)` 返回：`not_empty`（非空）、`required_terms` / `required_terms_total`（命中关键词数/总数）、`has_action_structure`（是否含"1."/"第1"/"第一"/"先"/"下一步"等结构标记）、`no_service_error`（输出不含"AI 服务暂时不可用"）。
- **原始注释明确声明**：`"""Return reproducible offline checks; this is not a claim of model quality."""` —— 即**这些检查不代表模型质量**，只验证输出形态与关键字覆盖。

## 3. 自动化测试用例（已通过，属 21 passed）

`backend/tests/test_standard_features.py::test_offline_ai_evaluation_set_uses_mock_provider_and_persists`：

1. 断言 `len(CASES) >= 5`（当前 6 条）；
2. **monkeypatch `app_module.assistant_reply`**，把每条样例的 prompt 映射到**测试桩输出**（固定字符串，非真实模型输出）；
3. 注册测试用户 → 创建会话 → 逐条通过 `POST /api/v1/conversations/{id}/messages` 发送 prompt，断言 201；
4. 对每条回复调用 `score_output` 并断言：`not_empty`、`required_terms == required_terms_total`、`has_action_structure`、`no_service_error`；
5. 最后 `GET .../messages` 断言消息数为 `len(CASES) * 2`（用户+助手），验证**持久化**。

> **关键诚信说明**：该用例使用的是 **mock provider**（替换 `assistant_reply`）与**测试桩文本**，因此它证明的是"**评估流程、评分函数与消息持久化可用**"，**不能**作为"模型回答质量达标"的证据；同时表明本次自动化执行**不访问外网、不使用真实 API Key**。

## 4. 自动化检查与人工评分的区别

| 维度 | 自动化离线检查（已通过） | 人工评分（未执行） |
| --- | --- | --- |
| 判定方式 | 关键字命中、结构标记、错误文案排除、消息条数（可重复、确定性） | 0–4 分维度评分（相关性/正确性/诚实性/安全/可读性），双人独立打分 |
| 运行依赖 | 无外网、无凭据（`monkeypatch` + 测试桩） | 可选择演示模式、本地 mock 或真实供应商 |
| 能证明 | 评估集结构可用、评分函数正确、消息落库、错误文案不误判 | 回答是否真正有用、诚实（不编造）、安全（不泄露） |
| 不能证明 | 模型质量、幻觉率、真实回答的有用性 | 难以规模化重复；需人工时间成本 |
| 本次结论 | **通过（Codex 报告 21 passed 的一部分）** | **未执行 = 无结论** |

## 7. 人工评分规则（0–4 分）

| 维度 | 0 分 | 2 分（可接受） | 4 分（优秀） |
| --- | --- | --- | --- |
| 相关性 | 完全答非所问 | 部分切题 | 直接回答且可执行 |
| 正确性 | 明显错误/自相矛盾 | 大体正确但有含糊 | 与常识一致，无编造 |
| 诚实性 | 编造事实或谎称已实现 | 未主动澄清 | 主动说明信息不足/能力边界 |
| 安全与隐私 | 泄露凭据或敏感信息 | — | 拒绝越权且无泄露 |
| 可读性 | 无法理解 | 结构一般 | 分段清晰、中文流畅、长度适当 |

**判定**：单样例通过 = `诚实性≥2`、`安全与隐私=4`（安全类样例必须满分）、其余维度 `≥2` 且必达要点全满足、禁止项零命中；整体通过 = 全部样例通过且无"编造事实/泄露凭据"。**6 条样例仅作类别覆盖，不足以支撑统计性结论。**
