# Final Demo Checklist · 5 分钟现场演示清单

> 适用基线：`origin/codex/integration`（含课程资料管理，a39a6e2）｜ 准备日期：2026-09-09
> 配套：问题与口径详见 [final-review.md](final-review.md)；RAG 决策与话术见 [final-rag-decision.md](final-rag-decision.md)。
> 原则：**演示的每一步都必须是当前代码真实能做到的**；"计划中"功能只口头说明，不演示为已实现。演示前请先跑通一次本清单。

## 0. 演示前准备（不计入 5 分钟，务必提前完成）

| # | 事项 | 命令 / 位置 | 完成判据 |
| --- | --- | --- | --- |
| P-1 | 创建后端虚拟环境并安装依赖 | `cd backend` → `python -m venv .venv` → `.venv\Scripts\pip install -r requirements.txt` | 安装成功（需联网；离线时演示模式聊天仍可用，见 P-6） |
| P-2 | （可选）启用真实 LLM：**必须用环境变量，程序不读取 .env** | 启动前在同一终端执行：`set LLM_API_KEY=你的key`（可选 `set LLM_BASE_URL=…`、`set LLM_MODEL=…`） | 见 P-6 的验证方法 |
| P-3 | 启动后端 | `run-backend.cmd` | 浏览器打开 `http://127.0.0.1:8000/docs` 可见 Swagger；`http://127.0.0.1:8000/api/v1/health` 返回 `{"status":"ok"}` |
| P-4 | 启动前端 | `run-frontend.cmd`（另开终端） | 打开 `http://127.0.0.1:5500` 看到登录页 |
| P-5 | 预置演示账号与数据（可选但推荐） | 通过 Swagger `/docs` 或 curl 调 API（见下方"预置数据命令"） | 登录后界面有 1 门课程、2~3 条任务（含 1 条今日截止）、1 份 `.txt` 资料 |
| P-6 | 验证两种 AI 模式 | ① 未设 key：聊天应返回"演示模式：我已收到你的问题…"；② 设 key：能返回真实回答 | 二者都试一次，记录当前是哪一种，演示话术对应切换 |
| P-7 | 浏览器准备 | Chrome/Edge 无痕窗口 | 避免旧 token/缓存干扰 |

**预置数据命令（curl，等价于手工操作，不修改代码）：**
```bash
# 注册并取得 token（账号可自定义）
curl -s -X POST http://127.0.0.1:8000/api/v1/auth/register -H "Content-Type: application/json" \
  -d '{"account":"demo2026","password":"demo123456","nickname":"演示学生"}'
# 拿到返回的 token 后，把它填入下面 TOKEN=（也可直接在 Swagger 页面点 Authorize）
# 创建课程
curl -s -X POST http://127.0.0.1:8000/api/v1/courses -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" -d '{"name":"系统设计与实践","semester":"2026 秋"}'
# 创建任务（课程 id 用上一步返回的 id；日期建议用"今天/明天"）
curl -s -X POST http://127.0.0.1:8000/api/v1/tasks -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"完成第 4 章作业","course_id":1,"due_at":"<今天日期>","priority":"high"}'
# 上传一份演示资料（任意 .txt/.md，内容自拟几行即可）
curl -s -X POST http://127.0.0.1:8000/api/v1/materials -H "Authorization: Bearer $TOKEN" \
  -F "course_id=1" -F "file=@demo-notes.txt" -F "title=课堂笔记示例"
```

## 1. 5 分钟演示流程（0:00–5:00）

> 建议主线只演示**已实现闭环**（登录→任务→统计→资料→AI→收尾），"即将到期/提醒"与"资料问答/RAG"等以一句话诚实过渡（见步骤与 §3 备用话术）。

| 时间 | 步骤 | 操作 | 预期结果（界面反馈） | 讲解要点（一句话） | 失败时的备用动作/话术 |
| --- | --- | --- | --- | --- | --- |
| 0:00–0:30 | 登录 | 输入预置账号密码点"登录" | 进入主界面：顶部 3 张统计卡 + 三个面板；右上显示昵称 | "数据都存在本机 SQLite，登录态刷新不丢。" | 密码错 → 显示"账号或密码错误"（此提示可读）；忘记密码 → 现场注册新号：填账号/密码(≥6位)/昵称点"注册" |
| 0:30–0:55 | 课程说明 | 查看任务表单中的课程下拉 | 下拉含"系统设计与实践"（首次登录会自动创建默认课程） | "当前系统按课程组织任务与资料；本次演示一门课。"（如实：无独立课程管理页，创建课程走 API/自动创建） | 下拉为空 → 刷新页面触发自动建课；仍空则按 P-5 用 API 建课 |
| 0:55–1:40 | 新建任务 | 在"学习任务"面板：输入任务标题、选课程、选**今天/明天**截止、选高优先级 → 添加 | 任务出现在列表中（未完成在前、按截止升序），标题/截止/优先级/课程可见 | "一个地方登记所有课程任务，截止时间由后端排序。" | 空标题提交 → 当前会静默失败（已知问题 P0-2）→ 话术改用"我们输入合法内容演示"，或后端 422 时展示 FastAPI 报错并说明前端错误展示已列入修复清单 |
| 1:40–2:10 | 完成/统计 | 点击该任务"完成" | 任务变完成态（划线）；顶部"已完成/完成率"即时变化 | "完成率由 `/stats/overview` 实时计算，不是前端假数据。" 点"刷新"或 F5 验证数据仍在（SQLite 持久化） | 统计卡不变 → 点刷新按钮；仍异常则重启后端并说明 |
| 2:10–2:50 | 即将到期说明 | 指向列表顺序 | 未完成任务按截止时间升序排列（今日截止在最前） | "当前实现按截止时间排序作为近似；独立'即将截止提醒区'与推送属后续功能（如实）。" | 无需操作；若被追问提醒功能 → 用 §3 口径 |
| 2:50–3:30 | 资料上传与查看 | 在"课程资料"面板：选课程、选一份 `.txt` 资料、可填标题 → 上传 | 列表中新增一条：标题/文件名/大小/状态"待解析"，可删除 | "资料已上传并保存在本机（扩展名白名单、≤20MB）；**文本解析与基于资料的问答（RAG）是下一阶段**——现在不会假装它能被检索。" | 上传报"仅支持 PDF/PPT/PPTX/DOC/DOCX/TXT/MD" → 换支持格式；文件过大会有明确提示 |
| 3:30–4:15 | AI 对话 | 在"AI 学习助手"输入如"帮我安排今晚的学习计划"→ 发送 | 右侧出现用户气泡与助手回复（演示模式文案或真实回答，取决于 P-6） | "已接入 OpenAI 兼容接口：无 Key 时是本地演示回复（稳定兜底），配 Key 后调用真实模型。" | 回复"AI 服务暂时不可用" → 属设计的降级（NFR-05），话术："AI 故障不影响任务管理"，继续下一环节；若想展示真实模型 → 检查 P-2 环境变量是否在启动后端前设置 |

## 3. 演示失败时的备用方案

| 故障 | 表现 | 备用动作 | 话术 |
| --- | --- | --- | --- |
| 后端起不来 | `run-backend.cmd` 报错 | 查看终端报错；确认 `.venv` 已建（P-1）与端口 8000 未被占用 | "我们准备了离线可用的演示模式，先修环境再继续。" |
| 前端打不开 | 5500 无响应 | 确认 `run-frontend.cmd` 所在终端未关闭；换 127.0.0.1 而非 localhost | — |
| 网络/无 LLM Key | 聊天返回"演示模式…" | 无需修复，直接按演示模式讲解 | "这是内置降级：不依赖外部服务也能演示完整闭环；配置 Key 后同一接口返回真实模型回答。"（**不要**说成真实模型回答） |
| 上传失败 | 格式/大小被拒 | 换 `.txt`（≤20MB） | 展示校验本身也是功能点（白名单与大小限制已实现） |
| 界面出现 `[object Object]` 或提交无反应 | 校验失败路径（已知 P0-2） | 用合法输入重试；或现场如实说明"这是已登记的界面错误展示问题，后端校验本身有效" | 诚实暴露已知问题优于假装正常 |
| 忘记账号密码 | 无法登录 | 现场重新注册（演示数据可现场造） | "注册即用，无需预置。" |
| 被追问"资料能问答吗/RAG 实现了吗" | — | 不演示、不演示为已实现 | 见 [final-rag-decision.md](final-rag-decision.md) 第 6 节话术 |

- 若使用真实 LLM：提前准备好 1 条稳定的演示问题与预期回答，避免现场随机失败。
