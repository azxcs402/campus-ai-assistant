# 06 · 测试计划（Test Plan）

> 文档编号：06 ｜ 状态：计划（随 TASK-002/003/005 的实现细化并回填执行结果）
> 覆盖：功能测试、异常/边界测试、AI 输出验证、用户体验测试、接口测试。需求/验收编号来自 [02-requirements.md](02-requirements.md)。

## 1. 测试目标与策略

- **目标**：保证基础版闭环可演示、标准版健壮可测、特色版 RAG 输出可信可溯源；
- **分层策略**：接口自动化为主（后端契约，FR-08/AC）、端到端冒烟为辅（核心用户旅程）、AI 输出用离线评估集验证（NFR-08）；
- **环境**：开发环境 + 演示环境（种子数据）；AI 依赖可在无外网情况下跳过并标记（NFR-05 降级验证）；
- **数据**：每套环境使用独立数据库与测试账号；**禁止使用真实个人信息与真实密钥**。

## 4. AI 输出验证（特色版重点）

> 原则：AI 回答必须可溯源、不编造（FR-14/15）；无相关内容如实告知。

### 4.1 离线评估集（Golden Set）

- 建立每课程 10–20 条「问题 → 期望覆盖点 + 期望引用资料」的评估集；
- 指标：**引用命中率**（回答引用的 source 是否真实存在于资料）、**内容相关度**（人工 1–5 分）、**拒答正确率**（资料中确实没有时是否正确说明"未找到"）；
- 门槛（初步，TASK-006 后校准）：引用命中率 ≥ 95%，无来源时拒答率 100%，相关度均分 ≥ 4。

### 4.2 专项用例

| 用例 ID | 场景 | 预期 |
| --- | --- | --- |
| AT-01 | 问资料中明确存在的内容 | 回答正确且引用来源与资料一致（AC-14/15） |
| AT-02 | 问资料中不存在的内容 | 回答"资料中未找到"，不编造（AC-14-2） |
| AT-03 | 引用定位抽查 | 点击来源能定位到该 chunk 的章节/页码（AC-15-1） |
| AT-04 | 多资料课程提问 | 引用可来自多份资料，来源均可追溯 |
| AT-05 | 删除/重传资料后再提问 | 不再引用已删除内容，重传后使用新内容（AC-13-2/3） |
| AT-06 | 恶意/超长/重复骚扰问题 | 长度与频率约束生效（429），不影响他人 |
